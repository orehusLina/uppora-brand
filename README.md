# Uppora brand kit

Всё, чтобы быстро собирать презентации и одностраничники в фирменном стиле Uppora (uppora.org).

## Что внутри

- `assets/` — логотипы и фото
  - `logo_dark.png` — тёмный логотип на прозрачном фоне (для светлого и зелёного фона), 985×208
  - `logo_light.png` — светлый логотип (для тёмного фона)
  - `hand_rock.png` — рука «коза» с зелёной точкой и тату uppora, фон #F7F7F7
- `skill/SKILL.md` — скилл для Claude: цвета, шрифты, фирменные приёмы, тон текста
- `templates/example/` — пример: презентация с идеями сборов для заинтересованного блогера

## Стиль коротко

| | |
|---|---|
| Акцент | `#00A63E` (на тёмном `#22C55E`, мелкий зелёный текст на светлом `#00843A`) |
| Тёмный | `#121512` |
| Текст | `#4B524C`, вторичный `#6B726C` |
| Фоны | `#F7F8F5`, `#E6F5EA`, `#00A63E`, `#121512` |
| Заголовки | Montserrat 800 |
| Текст | Manrope 400–700 |

Шрифты из Google Fonts:
`https://fonts.googleapis.com/css2?family=Montserrat:wght@500..800&family=Manrope:wght@400..700&display=swap`

## Про шаблоны

Слайды сделаны в формате Claude Slides (1920×1080, все стили inline). Картинки в нём ссылаются на ассеты исходной презентации (`/_blob/...`):

| В шаблоне | Файл |
|---|---|
| `/_blob/f3af17c875e3ad888d6627ece7001260` | `assets/logo_dark.png` |
| `/_blob/20715ed876245b1da7b0c6b66cfd7242` | `assets/logo_light.png` |
| `/_blob/6a41334b4382d5bd21b5866e2554b2f8` | `assets/hand_rock.png` |

Чтобы сделать новую презентацию, попросите Claude: «сделай презентацию в стиле Uppora для …» и дайте ссылку на этот репозиторий или файл `skill/SKILL.md`.
